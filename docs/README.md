## Forma de trabajo

Cada sesión contiene:

```text
README.md
     │
     ├── objetivo
     ├── orden
     ├── archivos
     ├── código
     ├── commits
     ├── validaciones
     └── resultado esperado
```

Las sesiones deben realizarse en orden.
